# Module 4 — Machine Learning Fundamentals

**Internship Project | Iris Flower Classification**

## Project Overview
This project demonstrates the basic machine learning workflow using Python and Scikit-learn. The Iris dataset is used to train a Logistic Regression classification model that predicts the species of an Iris flower from its sepal and petal measurements.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab / Jupyter Notebook

## Tasks Covered
- Learn the basic machine learning workflow
- Load and explore a beginner-friendly dataset
- Prepare features and target labels
- Split the dataset into training and testing sets
- Standardize numerical features
- Train a Logistic Regression model
- Test and evaluate the model
- Generate predictions for a new sample
- Display a confusion matrix

## Files
- `Machine_Learning_Fundamentals.ipynb` — Complete notebook
- `iris_dataset.csv` — Dataset used by the notebook
- `README.md` — Project documentation
- `requirements.txt` — Required Python packages

## How to Run
1. Open `Machine_Learning_Fundamentals.ipynb` in Google Colab or Jupyter Notebook.
2. Upload `iris_dataset.csv` if using Google Colab.
3. Run the cells from top to bottom.
4. Review the accuracy, classification report, confusion matrix, and prediction.

## Learning Outcome
The project demonstrates the complete supervised machine-learning workflow:

**Data → Preparation → Train/Test Split → Scaling → Model Training → Evaluation → Prediction**
