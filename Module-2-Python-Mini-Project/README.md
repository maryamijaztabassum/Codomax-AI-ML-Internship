# Python Mini Project – Expense Tracker

## Overview

This project is a simple command-line Expense Tracker developed in Python as part of the Codomax AI/ML Internship Module 2.

## Features

- Add new expenses
- View all expenses
- Calculate total expenses
- View category-wise expense summary
- Store expense data in a CSV file
- Menu-based user interface

## Technologies Used

- Python
- CSV
- OS

## Project File

- `expense_tracker.py` – Main Python program

## Learning Outcomes

This project helped me practice Python functions, loops, conditional statements, file handling, dictionaries, CSV data storage, and exception handling.
